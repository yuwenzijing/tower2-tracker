# Buyali · AION2 数据管理与采集助手

Buyali 是面向 AION2 玩家使用的角色数据与每周待办管理工具。网页用于管理账号、角色、奥德、道具等级、战斗力、基纳和待办事项；Windows 数据采集助手可从当前游戏窗口识别数据，并在用户确认后写入已配对的网页数据。

当前正式版本：`V1.3.3.1`

- 正式网站：[https://buyali.xyz](https://buyali.xyz)
- 最新版本：[GitHub Release V1.3.3.1](https://github.com/yuwenzijing/tower2-tracker/releases/tag/v1.3.3.1)
- Windows 采集助手：[下载 BuyaliCollector-v1.3.3.1.zip](https://github.com/yuwenzijing/tower2-tracker/releases/download/v1.3.3.1/BuyaliCollector-v1.3.3.1.zip)
- 完整更新内容：[V1.3.3 更新日志](V1.3.3更新日志.md)

## 主要功能

### 网页数据管理

- 按账号管理多个角色。
- 记录道具等级、战斗力、基纳、白奥德和蓝奥德。
- 管理角色与账号级每周待办，并按游戏重置时间自动处理周期。
- 支持同步口令，实现多设备间的数据同步。
- 支持数据导入、导出、撤回和采集写入提示。
- 支持为选中角色添加单行备注，长备注可悬停滚动查看。

### Windows 数据采集助手

- 识别当前游戏角色、白奥德、蓝奥德、基纳、战斗力和道具等级。
- 左键浮窗入口开始采集，右键查看角色信息。
- 写入前显示“变更前 / 变更后 / 变化”，允许人工修正。
- 识别角色与目标角色不一致时阻止自动写入。
- 支持配对、重新绑定、同账号筛选、写入撤回和自动更新。
- 原始截图只在本机内存中处理，不上传、不长期保存。

## 安装采集助手

1. 下载 `BuyaliCollector-v1.3.3.1.zip`。
2. 将压缩包完整解压到任意可写文件夹。
3. 打开解压后的 `BuyaliCollector-v1.3.3.1` 文件夹。
4. 运行根目录中的 `BuyaliCollector.exe`。
5. 保留 `_internal` 目录，不能删除、移动或改名。

程序为 Windows 便携版，无需安装 Python、OCR 引擎或其他运行环境。不要直接在压缩包预览窗口中运行。

## 首次配对

1. 打开并登录 [Buyali](https://buyali.xyz)。
2. 确认网页已设置同步口令。
3. 点击网页工具栏中的“数据采集”，生成 6 位一次性配对码。
4. 在采集助手中输入配对码并确认。
5. 助手显示“已配对”后即可开始采集。

配对码有效期为 5 分钟。更换同步口令、切换其他网页数据或执行“重新绑定”后，需要重新完成配对。

## 采集数据

1. 启动 AION2，并切换到需要采集的角色。
2. 打开游戏中能够显示目标数据的界面。
3. 左键点击游戏窗口上的采集浮窗。
4. 核对识别角色、写入位置和数据变化。
5. 如有需要，可直接修改“变更后”数值。
6. 点击“立即写入”，或等待倒计时结束后自动写入。

写入成功后会保留撤回入口。一个游戏界面没有展示且没有可靠识别的字段不会被随意修改；蓝奥德明确显示为 `0` 时会作为有效数据写入。

## 浮窗与常用操作

- 浮窗可以拖动到合适位置。
- 左键采集数据，右键打开或关闭角色信息面板。
- 设置中可选择仅显示当前账号的角色，并控制角色数据自动更新。
- 角色信息每 2 秒在后台检查一次，只在真实数据变化时重绘。
- 若浮窗在多显示器环境中不可见，可通过主窗口重置浮窗位置。
- 任务栏或系统托盘入口可显示/隐藏浮窗、重新绑定、取消当前采集或退出程序。

## 数据与隐私

- 游戏截图只在本机内存中用于 OCR 识别。
- 原始截图不会上传到 Buyali，也不会长期保存。
- 只有确认后的结构化字段会写入已配对的数据。
- 网络失败时，角色信息浮窗会明确标识缓存状态，不把旧数据伪装成最新数据。

## 使用提示

- 识别结果不正确时请点击取消，不要写入，然后确认打开了正确的游戏界面后重新采集。
- 当前程序未使用商业代码签名证书，Windows 或安全软件可能显示未知发布者提示。
- 请只从正式网站或本项目 GitHub Release 下载采集助手。

## 本地开发

采集助手源码位于 `collector/`，网页静态资源位于 `public/`，Cloudflare Worker 入口位于 `src/`。

- 采集助手本地运行：进入 `collector/` 后执行 `python main.py`
- 采集助手正式打包：执行 `collector/build.ps1`
- Worker 部署配置：`wrangler.toml`

采集助手服务地址可通过环境变量 `BUYALI_API_BASE` 覆盖。测试构建应连接独立测试环境，正式发布前必须确认版本号、接口地址、下载链接及自动更新通道全部指向正式版本。
